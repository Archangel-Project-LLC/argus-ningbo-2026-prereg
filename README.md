# Argus · Ningbo 2026 IWF World Championships · pre-registered predictions

Predictions for 215 lifters, fixed before any lifting (competition 27 Oct to 8 Nov 2026).

- `prereg/` : predicted totals, medal and bomb-out odds, one CSV per competition day, fingerprinted 26 Oct 2026 09:18 Cyprus (`MANIFEST.csv`).
- `prereg/attempts/` : attempt-by-attempt plans and the free-alternative baselines (entry total, last total, best in 12 months), fingerprinted 26 Oct 2026 11:37 Cyprus (`MANIFEST-attempts.csv`).
- `index.html` : the live tracker, updated after each session.

Both fingerprint lists were emailed to an independent party on 26 Oct 2026. Check any file with `shasum -a 256 prereg/*.csv prereg/attempts/*.csv`.
